Weight Stability — Feature Deep-Dive
Each feature shown with up to 3 overlaid metrics. Toggle metrics on/off or add features to compare. Solid = signed weight (left axis) · Dashed = running avg (left) · Dotted = running p-val (right, 0–1).
Metrics:
Instability guide:
< 1.0 — Stable Weight barely moves window to window. Trust it.
1–2 — Moderate Some drift but directionally consistent. Usable.
> 2 — Unreliable Weight flips or jumps between windows — model isn't learning a stable pattern.
The zero line is the key reference — a feature that repeatedly crosses zero (positive one window, negative the next) is directionally inconsistent and should be treated as noise regardless of average weight.
Feature Correlation Analysis
Highly correlated features compete for the same signal — the model swaps weight between them every window, causing instability. Use these views to identify redundant features to prune.
