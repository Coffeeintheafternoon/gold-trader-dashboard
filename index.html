Weight Stability — Top 5 Features Across Windows
Each line = one feature's signed weight across the 16 rolling train windows. Flat line = the model consistently learns the same relationship. Wild swings = noise.
Instability guide:
< 1.0 — Stable Weight barely moves window to window. Trust it.
1–2 — Moderate Some drift but directionally consistent. Usable.
> 2 — Unreliable Weight flips or jumps between windows — model isn't learning a stable pattern.
The zero line is the key reference — a feature that repeatedly crosses zero (positive one window, negative the next) is directionally inconsistent and should be treated as noise regardless of average weight.
